# ToonVector ⚡
### مستخلص خطوط الكوميكس والرسوم الكرتونية إلى متجهات (Vector SVG)
مبني بالكامل على تقنية **WebAssembly (WASM)** باستخدام خوارزميات **mkbitmap** ومحرك **Potrace** الرسمي من تطوير *Peter Selinger*.

---

## 🎯 مميزات التطبيق
* **استخلاص خطوط الحبر بدقة متناهية:** يعزل خطوط الكوميكس والمانغا والرسوم الكرتونية والمخطوطات من الخلفيات الملونة والظلال.
* **يعمل بالكامل داخل المتصفح (Client-side WebAssembly):** لا حاجة لخوادم معقدة أو لغات خلفية؛ كل المعالجة تتم على جهاز المستخدم مباشرة وبسرعة فائقة.
* **مكتبة أمثلة مدمجة:** تتضمن مثال الكوميكس الشهير من فيديو جوجل كروم الرسمي مع الإعدادات المثالية (`-f 2 -s 2 -t 0.48`).
* **إعدادات مسبقة سريعة:**
  - كوميكس الشريحة (`-f 2 -s 2 -t 0.48`)
  - مانغا وأنمي (`-f 3 -s 2 -t 0.44`)
  - توقيع وحبر يدوي (`-f 4 -s 2 -t 0.48`)
  - خطوط هندسية دقيقة (`-f 2 -s 3 -t 0.50`)
* **مقارنة تفاعلية متزامنة:** عارض مقارنة جنباً إلى جنب بين خطوط البتماب المعالجة والمنحنيات المتجهة الناتجة.
* **تصدير سهل:** تحميل ملف SVG أو نسخ الكود البرمجي بضغطة زر.

---

## 🚀 طريقة التشغيل المحلي (على جهازك)
1. اضغط مرتين على أيقونة **`VectorStudio`** الموجودة على سطح المكتب.
2. أو افتح موجه الأوامر في هذا المجلد وشغّل:
```bash
python server.py
```
3. سيفتح المتصفح تلقائياً على الرابط: `http://localhost:5050`.

## 🌐 خطوات الرفع على GitHub ونشره أونلاين مجاناً (GitHub Pages)

بما أن هذا التطبيق ثابت بالكامل (Pure Static HTML/JS/WASM)، يمكنك رفعه وتشغيله أونلاين في دقائق معدودة:

### 1. تجهيز المستودع:
افتح موجه الأوامر داخل المجلد `C:\Potrace\web`:
```bash
cd C:\Potrace\web
git init
git add .
git commit -m "Initial commit: ToonVector WebAssembly App"
```

### 2. الربط مع حسابك على GitHub:
1. اذهب إلى [GitHub.com](https://github.com) وأنشئ مستودعاً جديداً (New Repository) باسم مثلاً `toon-vector` (اجعله Public).
2. انسخ رابط المستودع ونفّذ الأمرين التاليين:
```bash
git remote add origin https://github.com/USERNAME/toon-vector.git
git branch -M main
git push -u origin main
```

### 3. تفعيل النشر المجاني (GitHub Pages):
1. في صفحة المستودع على GitHub، اضغط على **Settings** (الإعدادات).
2. من القائمة الجانبية اختر **Pages**.
3. تحت قسم **Build and deployment > Branch**، اختر فرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
4. خلال دقيقة واحدة، سيصبح موقعك متاحاً للعالم مجاناً على الرابط:
   `https://USERNAME.github.io/toon-vector/`

### 4. ربط نطاق مخصص (Custom Domain):
إذا اشتريت نطاقاً خاصاً بك (مثل `toonvector.com`):
* يمكنك كتابة اسم النطاق في حقل **Custom domain** داخل صفحة GitHub Pages، وسيتم توجيهه وتفعيل شهادة الأمان SSL مجاناً وتلقائياً.
